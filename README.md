# 小米平板 6S Pro 12.4 · HarmonyOS NEXT

[English](README.en.md) · [构建说明](docs/BUILDING.md) · [源码索引](docs/SOURCE_MAP.md) · [测试记录](docs/VERIFICATION.md) · [来源与许可](docs/PROVENANCE.md)

这是小米平板 6S Pro 12.4（**sheng**）的 HarmonyOS NEXT 移植项目。通过兼容层适配显示、触控、音频和无线等硬件，目前已能进入鸿蒙桌面并使用部分系统及第三方应用。

其他机型也可以参考部分的代码和思路；思路就是把华为的system，vendor，sys_prod，以及自己机器的vendor_dlkm打包super并刷入，然后提取自己机器的boot，vendor_boot，init_boot，改挂载点，做出USB串口，然后根据日志来修开机；我这个方案是不动super分区，修复的源码接口放在vendor_boot，开机时释放到内存，挂载到/compat。

仓库提供各功能当前使用的源码、启动配置和构建工具。系统还有不少功能需要完善，具体进度见下表。

## 功能进度

| 功能 | 当前情况 | 待完善内容 |
| --- | --- | --- |
| 启动与桌面 | 可以启动、进入桌面、打开窗口并截取系统画面。 | 开机约需三分钟，部分应用和服务仍有等待、卡顿或崩溃，长期稳定性需要继续改进。 |
| 屏幕显示 | 已实现完整屏幕输出，修复早期只有顶部正常显示的问题。 | 曾出现黑条、白屏和唤醒异常，仍需检查反复亮灭屏及长时间使用的稳定性。 |
| GPU 与刷新率 | 已接入 Mesa/Turnip/Zink 图形支持，显示模式为 3048×2032、120Hz，使用内核原生 GPU 调频。 | 144Hz 尚未完成，图形性能、格式兼容和画面同步仍需优化；120Hz 显示模式不代表所有应用都能达到 120fps。 |
| 触控与操作响应 | 触摸坐标和日常操作可用，已修复一处导致点击应用后等待一至两秒的服务阻塞。 | 部分应用启动和动画仍有卡顿，触摸采样、多点触控、边缘操作及休眠恢复需要进一步测试。 |
| 亮度 | 手动亮度调节可用。 | 自动亮度、最低亮度和休眠后的恢复需要继续测试。 |
| 电源键与音量键 | 短按电源键可以熄屏、亮屏，长按可以打开关机菜单；音量键已接入系统。 | 锁屏、休眠及连续操作时的按键行为还需全面测试，深度休眠功耗尚未评估。 |
| Wi-Fi | 可以输入密码、连接网络并上网，已测试 5GHz、160MHz 的 Wi-Fi 6 连接。 | 偶尔存在速度下降或连接失效，漫游、待机重连、热点和长期稳定性尚未完成测试。 |
| Wi-Fi 协议显示 | 状态栏可以显示实际连接的 Wi-Fi 6 标识。 | Wi-Fi 7 实际连接尚未测试。 |
| 蓝牙 | 可以开关、关闭后重新开启并发现附近设备。 | 配对、蓝牙耳机通话与播放、键鼠和 BLE 尚未完整验证；设备不支持星闪。 |
| 扬声器与音频 | 音乐、视频、暂停后继续播放和开机动画声音可用。 | 音质、全部扬声器声道、长时间播放、耳机、USB 音频和蓝牙音频需要继续测试，录音尚未完成。 |
| 视频与图片 | 部分软件解码路径可用，部分系统及第三方应用能够显示视频和图片。 | 硬件视频解码尚未完成，部分格式或应用仍可能播放失败、卡顿。 |
| 输入法 | 可以弹出键盘并输入内容，已用于输入 Wi-Fi 密码。 | 更多应用、网页输入框和多语言场景需要测试。 |
| 第三方应用与预装应用 | 已接入 preload 应用安装，修复部分应用启动时的“应用数据解密中”拦截，抖音等应用能够进入并显示内容。 | 部分应用仍停留在启动画面或闪退，登录和依赖网页的功能存在问题。 |
| 用户数据 | 整个 userdata 分区直接挂载为 `/data`，保留首次开机向导。 | 升级、回滚及新设备初始化流程需要完善。 |
| 电池与充电状态 | 可以读取真实电量和充电状态，系统显示不再固定为 100%。 | 充电状态变化、温控、快充、续航和待机耗电需要继续测试。 |
| 时间同步 | 联网时间同步已可用。 | 离线时间、时区和部分界面的时间显示仍有不一致。 |
| USB 调试 | 提供命令执行、文件传输和截图工具。 | 重启或 USB 状态变化后仍可能失去响应，调试连接的可靠性需要继续改进。 |
| A/B 启动 | 可以在桌面启动完成后标记本次启动成功。 | 完整 OTA 和 A/B 升级流程尚未实现。 |
| 网页与 WebView | 尚未修好。 | 部分网页无法打开或显示空白，抖音网页登录仍可能一直加载。 |
| 安全与加密 | 有软件兼容实现，支持部分系统服务和应用运行。 | TEE、硬件密钥、锁屏凭据及 HUKS 仍未完整适配，不能提供原厂同等的安全保障；应用市场加密版应用不能解密使用；支付、DRM 等功能未验证。 |
| 相机、麦克风、传感器及配件 | 尚未完成。 | 相机成像、录音、传感器、手写笔和键盘配件需要分别适配和测试。 |
| 跨设备协同 | 尚未完成。 | 设备发现、连接及跨设备功能仍需适配。 |

## 三个启动分区的改动

| 分区 | 改动内容 |
| --- | --- |
| `boot` | 使用与原机官方系统配置及符号版本匹配的 5.15.178 GKI 内核，补充鸿蒙进程通信所需的接口。 |
| `init_boot` | 提供最小启动入口，建立必要路径后，将启动流程交给 `vendor_boot` 中的程序。 |
| `vendor_boot` | 在启动内存盘中存放兼容层及配置，随开机加载显示、触控、无线、音频和系统服务适配。 |

## 源码目录

- `compat/`：按功能划分的兼容层源码、接口和共享依赖。
- `runtime/`：启动脚本与运行配置。
- `patches/donor/`：鸿蒙原系统库的补丁配方，包含文件哈希和修改位置校验。
- `external/`：依赖的上游源码信息、内核与 Mesa 补丁及许可。
- `tools/`：构建与源码校验工具。
- `output/`：电脑端调试、传输、截图、备份与恢复脚本。
- `tests/`、`analysis/`、`evidence/`：测试用例及去除私人信息的测试记录。

每个功能保留当前使用的实现和必要依赖。详细文件说明见[源码索引](docs/SOURCE_MAP.md)，文件清单和校验值见 `SOURCE-SELECTION.json`、`SOURCE-MANIFEST.json` 与 `SHA256SUMS`。

## 构建与使用

构建环境使用 WSL。请先按[构建说明](docs/BUILDING.md)准备 SDK、上游源码和链接依赖，再查看可构建的目标：

```sh
python3 tools/build_current.py --list
```

UserIAM 相关组件通过 `tools/build_useriam.py` 构建。仓库目前提供兼容层及相关组件的构建流程，完整 ROM 仍需要另行准备系统镜像、固件和应用等内容。这些文件不随源码分发。

系统内的 USB 调试使用 `output/` 中的工具，命令需要依次执行。刷入前请备份本机的三个启动分区，并核对机型和镜像校验值。测试范围和记录见[测试文档](docs/VERIFICATION.md)。
