# Xiaomi Pad 6S Pro 12.4 · HarmonyOS NEXT 移植研发源码

[English](README.en.md) · [构建与目录说明](docs/BUILDING.md) · [上游与许可证](docs/PROVENANCE.md) · [验证记录](docs/VERIFICATION.md)

这是小米平板 6S Pro 12.4（代号 **sheng**）运行 HarmonyOS NEXT 用户态的实验项目，通过独立兼容层接入小米原机硬件。当前 `super` 内仅 `vendor_dlkm` 保留小米原装。目前已进入真实鸿蒙桌面，触控、部分应用、Wi-Fi、扬声器输出等已有真机验证，仍有电源管理、WebView、性能和外设适配问题。

**状态快照：2026 年 10 月 30 日，北京时间。** 本仓库发布的是源码、补丁、配置和构建记录，不包含可直接刷入的完整 ROM、华为闭源系统源码、原厂镜像、固件二进制、用户数据或账号令牌。历史目录包含失败与撤回的试验，不能全部叠加使用。

## 当前版本与结论

| 版本 | 作用 | 已得到的结论 |
| --- | --- | --- |
| v118 | 载荷布局基线 | 主兼容载荷迁入 `vendor_boot`；`init_boot` 保留最小入口。 |
| v143 | 本次电源修复前的参考基线 | 桌面启动、视频扬声器输出与开机声音已有分项验收；WebView 仍未修复。 |
| v144 | 独立 EGL/WebView 试验 | 原生测试中的 resize / 首次 swap 问题已复现并局部修复，真实网页仍白屏；未做持久发布。 |
| **v145** | **当前持久版本，熄屏修复已获用户确认** | 镜像读回哈希匹配，重启进入桌面；正确唤醒调用顺序已生效，关屏期间的晚到帧已被拦截。**用户最新实测确认熄屏已正常。** |

版本号是研发轮次，不表示每一版都通过、都曾刷入或适合日常使用。v145 镜像 SHA-256：`bf39eaa2f45386d09621a9a4cfbbd4725e673cb046fb777d277a40eea70e6895`；v143：`74ee88b754f0d62fbd44df964a925d8ca8aaca3592e18ae01aae7ef46ebc4d58`。这些镜像不在源码包内。

## 启动分区改动

| 分区 | 改动内容 |
| --- | --- |
| `boot` | 换用匹配 sheng 官方 303 配置和符号版本的 5.15.178 GKI 内核，补充鸿蒙 IPC 模块需要的内核导出接口。 |
| `init_boot` | 将启动入口替换为 v118 最小 PID1 程序，建立所需路径并转入 `vendor_boot` 中的启动程序。 |
| `vendor_boot` | 在 ramdisk 中加入 `/sheng-compat-v118/` 主兼容载荷和 `/sheng-audio-v1/` 音频载荷，存放启动程序、适配库、模块及配置。显示、触控、无线、音频和框架等修复由此持久加载；v145 更新了显示电源适配与唤醒程序。 |

## 源码入口

- `compat/`：显示、触控、音频、无线、框架、电源与内核适配源码及配置；保留历史目录便于审查。
- `tools/`：构建、二进制补丁配方、镜像校验、诊断和研发辅助脚本。
- `external/custom/`：从 WSL 补齐的自定义图形端口、IPC、UserIAM 等源文件。
- `external/patches/`、`external/overlays/`：相对于记录的公开上游版本的差异与新增源码。
- `external/upstream-sources.json`、`external/licenses/`：上游 URL、精确提交和许可证原文。
- `analysis/`：选入的补丁、配置和构建验证报告；不含完整私人设备日志。
- `output/*.ps1`：主机侧脚本源码；不包含镜像、设备备份或平台工具二进制。
- `docs/`：构建边界、模块索引和验证说明；`SOURCE-MANIFEST.json` 提供打包后文件的大小与哈希。

最新电源修复入口：`tools/build_screen_power_v145.py`、`tools/native_display_wake_v2.cpp`、`tools/build_vendor_screen_power_v145.py`；短按熄屏已获用户验收。WebView 的 v144 与撤回的 GPU 调频、DSC 猜测修补等均属于历史/实验代码，不能仅因存在于仓库就认为应该启用。

## 构建与贡献

请先读 [BUILDING.md](docs/BUILDING.md)。当前是**研发源码快照**，尚未完成从全新环境到完整 ROM 的一键可复现构建。原厂与 donor 闭源输入、SDK、工具链以及部分基线镜像须自行合法准备；历史脚本还包含开发目录布局、输入哈希及需配置的路径。

调试应沿 `原始事件 → MMI → 系统服务 → DMS/RenderService → HDI/VDI → DRM/背光` 逐段验证。系统截图证明合成内容，不单独证明物理灭屏；协商链路速率不等于下载吞吐；返回成功不等于有声或真实出图。

提交问题时请提供版本、复现步骤、预期/实际行为及脱敏日志。不要提交 Wi-Fi 密码、令牌、用户数据、原厂镜像或闭源提取库。上游项目尤其是 [AnyHarmonyOS](https://github.com/YiKongk/AnyHarmonyOS) 的参考与派生关系见 [PROVENANCE.md](docs/PROVENANCE.md)；本项目不代表小米、华为或上游项目的官方适配。
