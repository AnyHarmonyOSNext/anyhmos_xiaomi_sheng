# 小米平板 6S Pro 12.4 · HarmonyOS NEXT

[English](README.en.md) · [构建说明](docs/BUILDING.md) · [源码索引](docs/SOURCE_MAP.md) · [验收记录](docs/VERIFICATION.md) · [来源与许可](docs/PROVENANCE.md)

面向小米平板 6S Pro 12.4（**sheng**）的 HarmonyOS NEXT 实验移植。通过兼容层连接鸿蒙用户态与原机硬件，现已运行真实鸿蒙桌面。当前 `super` 内仅 `vendor_dlkm` 保留小米原装。

**当前验收版本：v146，2026 年 10 月 31 日。** 本仓库每个功能只保留当前最完善、纳入可用基线的源码及其必要依赖，旧实现、重复副本、失败实验和逐轮构建链已从当前文件树移除。

## 本次实际验证

整理后的源码在 WSL 中完成 37 个直接构建目标及 UserIAM 后端、适配层和驱动编译。将其中 34 个运行文件打入 v146 测试包，先备份设备，再从 TWRP 写入 `vendor_boot_a`，整分区读回 SHA-256 一致，随后重启验收。最小 init 重编译结果与既有入口完全一致；本轮内核和 Mesa 沿用对应已验证产物，没有重新完整构建。

本轮自动启动约 **171.73 秒**完成；桌面解锁、原生系统截图、Wi-Fi/音频/蓝牙启动流程均有日志。用户确认**原本应正常的既有功能均正常**，随后授权发布。这不代表原先未完成的功能也已修复，也不等于完整性能或长期稳定性测试。

测试镜像 SHA-256：`6bdb19aa74a42de27ba32e6e23fcf87f1944acd23be604a8f99785400453b901`。镜像、闭源系统库、固件、应用、用户数据和原始私人日志不随源码分发。详细记录见 `analysis/rebuilt-source-v146-verification.json`。

## 三个启动分区的改动

| 分区 | 当前改动 |
| --- | --- |
| `boot` | 使用匹配 sheng 官方 303 配置、符号版本的 5.15.178 GKI 内核，补充鸿蒙 IPC 所需的导出接口。 |
| `init_boot` | 保留最小 PID1 入口，建立路径后转交 `vendor_boot` 中的启动程序。本轮重编译入口与既有入口逐字节相同。 |
| `vendor_boot` | 在 ramdisk 内放置 `/sheng-compat-v118/` 与 `/sheng-audio-v1/`，持久加载启动、显示、触控、无线、音频和框架适配。v146 使用本次重编译的运行文件及对应校验配置。 |

## 当前源码在哪里

- `compat/`：按功能划分的当前源码、接口头和共享依赖。
- `runtime/`：与已验收 v146 对应的启动脚本及配置；运行时文件名保持兼容。
- `patches/donor/`：原库修补配方，校验输入、输出 SHA-256 及逐段字节。
- `external/`：上游版本、所需 Mesa/内核差异、overlay 和许可。
- `tools/`：直接构建和源码清单工具；`output/*.ps1`：主机调试、备份与恢复工具。
- `tests/`、`analysis/`、`evidence/`：必要测试和脱敏验证记录。

显示/熄屏采用 v145 实现、buffer v130、Turnip v128、EGL v126、触控 service-v2、音频 v142、Wi-Fi 代际 v134、蓝牙 v139 加 v141 能力纠正、电池 v131、数据库/内存管理 v2、USB probe v121。它们共同组成当前基线。UserIAM 4.0 后端和 4.1 适配层均是当前依赖；文件中的旧编号不代表同时保留了多套历史实现。逐文件选择与哈希见 `SOURCE-SELECTION.json`、`SOURCE-MANIFEST.json` 和 `SHA256SUMS`。

## 构建与使用

先阅读 [BUILDING.md](docs/BUILDING.md)，配置匹配 SDK、上游源码、libdrm、PAL、OpenSSL 与 donor 链接输入，再使用 `tools/build_current.py --list` 查看目标。UserIAM 由 `tools/build_useriam.py` 构建。这是研发源码，尚不是从全新环境一键生成完整 ROM 的工程。

COM 调试通道不是标准 ADB；使用 `output/` 中的命令、传输和截图脚本，串口操作必须串行。刷机需保存本设备自己的三个启动分区备份并核对镜像哈希。不能将其他机型镜像或测试结果直接套用。
